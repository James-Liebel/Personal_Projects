Where The Tracks Connect

These categories are separate on paper, but the portfolio works where they overlap.

Engineering -> Science
Clean pipelines feed better modeling. Feature engineering, SQL prep, ETL cleanup, and schema decisions shape whether the science layer has usable training data.
Science -> Analysis
Metrics need explanation to matter. Evaluation results, benchmark framing, and plain-language visuals turn model performance into something another person can understand.
Analysis -> Engineering
Readable outputs force better systems. Dashboards, semantic models, APIs, and interactive front ends create pressure for cleaner structure, stronger delivery, and more reusable data flows.
